# unicode-protect
欢迎光临本网站的文件存储库！PS：你只能拿走一个名为app.py的文件\n
该网站旨在为用户提供更新的、更安全的加密方式。通过python中的flask以及其他模块，使用一种新型的加密方式————Vigenère+AES+unicode方块加密，对尝试破解的人造成迷惑。也就是说，先用Vigenère方式进行基础加密，再用AES进行深度加密，最后用unicode进行视觉加密，安全程度高且解密方便，只需知道AES密钥和Vigenère关键字就可以对密文轻松解密。
注意：使用unicode加密方式前，请先确认您的设备是否支持unicode。若不支持，您最多可以使用AES和Vigenère方式，使用unicode会看不到密文。
